# Hardware Exposure Lab – Arduino Projects

Projects built for the Hardware Exposure Lab at Tel Aviv University by
[Raz Tassa](https://www.linkedin.com/in/raz-tassa-3407722a6/) and
[Wasem Bkriya](https://www.linkedin.com/in/wasem-bk/).
Firmware is written in C/C++ for Arduino; the vision project adds a Python/OpenCV host script.

| Project | What it does | Folder |
|---|---|---|
| Ball & Beam | PID controller that balances a ball at a target position on a servo-driven beam | [BALL AND BEAM](ARDUINO%20PROJECTS/BALL%20AND%20BEAM) |
| Face-Tracking Pan/Tilt | Camera mount that keeps a face centred using OpenCV and two servos | [FACE REC AND TRACKING WITH OPENCV](ARDUINO%20PROJECTS/FACE%20REC%20AND%20TRACKING%20WITH%20OPENCV) |
| Gesture-Controlled Vehicle | Glove with an IMU that steers a car over an nRF24 radio link | [CAR AND GLOVE](ARDUINO%20PROJECTS/CAR%20AND%20GLOVE) |
| UART Lab | Two Arduinos exchanging data over a serial link | [UART_LAB](ARDUINO%20PROJECTS/UART_LAB) |

Each folder has its own README with the wiring, how the code works, and a demo video or lab report where available.
